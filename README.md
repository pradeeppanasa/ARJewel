# Jewellery AR Try-On

Virtual try-on for earrings and necklaces using MediaPipe face landmark detection.

- Upload a photo or use your camera
- Browse the jewellery gallery and select a piece
- Instantly see it overlaid on your photo
- AI-powered photorealistic overlay via Flux Kontext Pro (requires BFL_API_KEY)
- Style recommendations via Azure OpenAI GPT-4o (requires Azure credentials)
